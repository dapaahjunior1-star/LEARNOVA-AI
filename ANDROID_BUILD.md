# LEARNOVA AI — Android Build Guide

This project is Android-ready using Capacitor.

## What you need

- Node.js 20+
- Android Studio
- Android SDK
- A physical Android phone with Developer Options + USB debugging enabled

## 1. Install project dependencies

From the project folder:

    npm install

Then install Capacitor:

    npm install @capacitor/core @capacitor/android
    npm install -D @capacitor/cli

## 2. Add Android

    npx cap add android
    npx cap sync android

If the `android/` folder was generated by Capacitor, open it with:

    npx cap open android

## 3. Connect your phone

On your Android phone:

Settings → About phone → tap Build number several times → Developer options → USB debugging ON.

Connect the phone by USB and accept the computer authorization prompt.

In Android Studio, select the phone and press Run.

## IMPORTANT: the AI server

The APK should NOT contain your OpenAI API key.

For local testing, run the LEARNOVA server on your computer:

    npm install
    cp .env.example .env
    # add OPENAI_API_KEY to .env
    npm start

Then make the phone able to reach the computer on the same Wi-Fi network.

The frontend currently calls `/api/...`, so the Android WebView needs to be pointed at your reachable LEARNOVA server for development. For a production build, deploy the server behind HTTPS and configure the app to use that production URL.

## 4. Build an installable APK

Android Studio:
Build → Build Bundle(s) / APK(s) → Build APK(s)

For Google Play, create a signed Android App Bundle (AAB):
Build → Generate Signed Bundle / APK → Android App Bundle.

## Suggested production architecture

Android app
    ↓ HTTPS
LEARNOVA backend
    ↓
OpenAI API
    ↓
AI response

This protects your API key and lets you control authentication, rate limits, PDF quotas, and costs.
